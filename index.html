Exemples d'utilisation

🍰 Recette (réduire une portion)

Situation : Une recette pour 4 personnes, je veux pour 6 personnes

Données :

  • A = 4 (personnes initiales)
  • B = 200g (farine pour 4)
  • C = 6 (personnes désirées)
  • X = ? (farine pour 6)

→ X = 300g de farine

🚗 Vitesse et Distance

Situation : Je fais 150km en 2h, combien en 5h ?

Données :

  • A = 2 (heures)
  • B = 150 (km parcourus)
  • C = 5 (heures futures)
  • X = ? (km futurs)

→ X = 375km

📊 Prix à la pesée

Situation : 300g de fromage coûtent 7.50€. Combien coûte 500g ?

Données :

  • A = 300 (grammes)
  • B = 7.50€ (prix pour 300g)
  • C = 500 (grammes désirés)
  • X = ? (prix pour 500g)

→ X = 12.50€

⚖️ Conversion d'unités

Situation : 5 euros, c'est combien en dollars ? (1€ = 1.10$)

Données :

  • A = 1 (euro)
  • B = 1.10 (dollar par euro)
  • C = 5 (euros à convertir)
  • X = ? (dollars)

→ X = 5.50$
